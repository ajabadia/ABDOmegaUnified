Recomendación
En tu caso, cada ruta de la matriz ya nace con amount bipolar y además tienes “via” secundaria, así que eliminar el control de cantidad del propio slot haría la UX peor y obligaría al usuario a crear nodos intermedios para una operación que debería ser inmediata. Por qué el knob es mejor
El amount en el slot resuelve el 90% de los casos musicales: “LFO a cutoff”, “ENV a pitch”, “velocity a VCA”, “aftertouch a vibrato”. Si obligas a insertar siempre un módulo de atenuación, conviertes una acción de una intención en una pequeña construcción modular, y eso penaliza justo la inmediatez que una matriz debe aportar.

Además, tu runtime ya está pensado para pesos por conexión y sinks que suman modulación total por destino, así que el modelo conceptual del sistema ya asume que cada ruta tiene su propia ganancia. Eso significa que el knob no es un añadido superficial de UI, sino la representación directa de algo que el motor ya entiende muy bien.

Cuándo usar atenuadores
Los atenuadores y multiplicadores sí son valiosos, pero como segunda capa. En tu propio sistema de modulación ya aparecen nodos Multiply, Mix y Curve, y la documentación los describe precisamente para depth control, suma y remapeo de señales dentro del grafo.

Úsalos para estos casos:

Escalar una fuente una sola vez y reutilizarla en varias rutas.

Combinar dos moduladores antes de llegar al destino.

Hacer modulation-of-modulation más sofisticada que un simple via.

Aplicar curvas, compresión de rango o transformaciones no lineales.

ts
// components/ModuleModMatrix.ts

type ModMatrixSlot = {
  active: boolean;
  source: string;
  target: string;
  amount: number;
  via: string;
  viaAmount: number;
};

class ModuleModMatrix {
  el: HTMLElement;
  content: HTMLElement;
  options: any;
  state: any = null;
  slots: ModMatrixSlot[] = [];
  activityValue = 0;
  pulseRaf: number | null = null;

  constructor(el: HTMLElement, content: HTMLElement, options: any) {
    this.el = el;
    this.content = content;
    this.options = options;
    this.renderBase();
  }

  async init() {
    this.bind();
    await this.refreshFromState();
  }

  async refreshFromState() {
    const state = window.moduleManager?.lastState || null;
    this.state = state;

    const slots = state?.preset?.modMatrix || state?.modMatrix || [];
    this.slots = this.normalizeSlots(slots);

    this.updateCount();
    this.updateActivityFromSlots();
  }

  normalizeSlots(raw: any[]): ModMatrixSlot[] {
    const out: ModMatrixSlot[] = [];
    for (let i = 0; i < 32; i++) {
      const slot = raw?.[i] || {};
      out.push({
        active: !!slot.active,
        source: slot.source || '',
        target: slot.target || '',
        amount: typeof slot.amount === 'number' ? slot.amount : 0,
        via: slot.via || '',
        viaAmount: typeof slot.viaAmount === 'number' ? slot.viaAmount : 0
      });
    }
    return out;
  }

  renderBase() {
    this.content.innerHTML = `
      <div class="omega-matrix-launcher">
        <div class="omega-matrix-launcher__top">
          <div class="omega-matrix-launcher__display">
            <span class="omega-matrix-launcher__count" id="matrix-active-count">00</span>
          </div>
          <div class="omega-matrix-launcher__led" id="matrix-activity-led"></div>
        </div>

        <div class="omega-matrix-launcher__meta">
          <div class="omega-matrix-launcher__label">MOD MATRIX</div>
          <div class="omega-matrix-launcher__sub" id="matrix-summary-line">NO ACTIVE ROUTES</div>
        </div>

        <button class="omega-matrix-launcher__button" id="matrix-open-btn">
          MATRIX
        </button>
      </div>
    `;
  }

  bind() {
    const btn = this.content.querySelector('#matrix-open-btn') as HTMLButtonElement | null;
    if (btn) {
      btn.onclick = (e) => {
        const mode = e.shiftKey ? 'overview' : 'compose';
        window.dispatchEvent(new CustomEvent('omega:matrix-open', {
          detail: { mode }
        }));
      };
    }
  }

  updateCount() {
    const countEl = this.content.querySelector('#matrix-active-count');
    const summaryEl = this.content.querySelector('#matrix-summary-line');
    if (!countEl || !summaryEl) return;

    const active = this.slots.filter(s => s.active).length;
    countEl.textContent = String(active).padStart(2, '0');

    if (active === 0) {
      summaryEl.textContent = 'NO ACTIVE ROUTES';
      return;
    }

    const strongest = this.slots
      .filter(s => s.active)
      .sort((a, b) => Math.abs(b.amount) - Math.abs(a.amount))[0];

    if (strongest?.source && strongest?.target) {
      summaryEl.textContent = `${strongest.source} → ${strongest.target}`;
    } else {
      summaryEl.textContent = `${active} ACTIVE ROUTES`;
    }
  }

  updateActivityFromSlots() {
    const led = this.content.querySelector('#matrix-activity-led') as HTMLElement | null;
    if (!led) return;

    const activeSlots = this.slots.filter(s => s.active);
    const total = activeSlots.reduce((acc, s) => acc + Math.abs(s.amount || 0), 0);
    const avg = activeSlots.length ? total / activeSlots.length : 0;

    this.activityValue += (avg - this.activityValue) * 0.22;
    led.style.setProperty('--matrix-activity', this.activityValue.toFixed(3));
    led.classList.toggle('is-active', this.activityValue > 0.02);
  }

  onStateUpdate(state: any) {
    this.state = state;
    this.slots = this.normalizeSlots(state?.preset?.modMatrix || state?.modMatrix || []);
    this.updateCount();
    this.updateActivityFromSlots();
  }

  destroy() {
    if (this.pulseRaf) cancelAnimationFrame(this.pulseRaf);
  }
}

// stores/matrixstore.ts

export type ModMatrixSlot = {
  active: boolean;
  source: string;
  target: string;
  amount: number;
  via: string;
  viaAmount: number;
};

export type MatrixMode = 'compose' | 'overview';

export type MatrixFilterState = {
  showActiveOnly: boolean;
  source: string | null;
  target: string | null;
  onlyWithVia: boolean;
};

export type MatrixUiState = {
  open: boolean;
  mode: MatrixMode;
  selectedSlotIndex: number | null;
  lastEditedSlotIndex: number | null;
  soloSlotIndex: number | null;
  mutedSlots: Set<number>;
  filters: MatrixFilterState;
  pendingWrites: Set<string>;
};

export class MatrixStore {
  slots: ModMatrixSlot[] = [];
  ui: MatrixUiState = {
    open: false,
    mode: 'compose',
    selectedSlotIndex: null,
    lastEditedSlotIndex: null,
    soloSlotIndex: null,
    mutedSlots: new Set(),
    filters: {
      showActiveOnly: true,
      source: null,
      target: null,
      onlyWithVia: false
    },
    pendingWrites: new Set()
  };

  loadSlots(raw: any[]) {
    this.slots = [];
    for (let i = 0; i < 32; i++) {
      const slot = raw?.[i] || {};
      this.slots.push({
        active: !!slot.active,
        source: slot.source || '',
        target: slot.target || '',
        amount: typeof slot.amount === 'number' ? slot.amount : 0,
        via: slot.via || '',
        viaAmount: typeof slot.viaAmount === 'number' ? slot.viaAmount : 0
      });
    }
  }

  getAllSlots() {
    return this.slots.map((slot, index) => ({
      ...slot,
      index,
      isMuted: this.ui.mutedSlots.has(index),
      isSolo: this.ui.soloSlotIndex === index,
      isSelected: this.ui.selectedSlotIndex === index,
      isPending: this.ui.pendingWrites.has(String(index))
    }));
  }

  getActiveCount() {
    return this.slots.filter(s => s.active).length;
  }

  getSelectedSlot() {
    const idx = this.ui.selectedSlotIndex;
    return idx == null ? null : { ...this.slots[idx], index: idx };
  }

  getComposeSlots() {
    let rows = this.getAllSlots();

    if (this.ui.filters.showActiveOnly) {
      rows = rows.filter(s => s.active || s.index === this.ui.selectedSlotIndex);
    }
    if (this.ui.filters.source) {
      rows = rows.filter(s => s.source === this.ui.filters.source);
    }
    if (this.ui.filters.target) {
      rows = rows.filter(s => s.target === this.ui.filters.target);
    }
    if (this.ui.filters.onlyWithVia) {
      rows = rows.filter(s => !!s.via);
    }

    return rows;
  }

  getOverviewSlots() {
    return this.getAllSlots();
  }

  getFirstFreeSlotIndex() {
    const index = this.slots.findIndex(s => !s.active && !s.source && !s.target);
    return index >= 0 ? index : null;
  }

  selectSlot(index: number | null) {
    this.ui.selectedSlotIndex = index;
  }

  setMode(mode: MatrixMode) {
    this.ui.mode = mode;
  }

  createDraftAtFirstFree() {
    const idx = this.getFirstFreeSlotIndex();
    if (idx == null) return null;

    this.slots[idx] = {
      active: true,
      source: '',
      target: '',
      amount: 0,
      via: '',
      viaAmount: 0
    };

    this.ui.selectedSlotIndex = idx;
    this.ui.lastEditedSlotIndex = idx;
    return idx;
  }

  patchSlot(index: number, patch: Partial<ModMatrixSlot>) {
    this.slots[index] = { ...this.slots[index], ...patch };
    this.ui.lastEditedSlotIndex = index;
  }

  clearSlot(index: number) {
    this.slots[index] = {
      active: false,
      source: '',
      target: '',
      amount: 0,
      via: '',
      viaAmount: 0
    };
    this.ui.mutedSlots.delete(index);
    if (this.ui.soloSlotIndex === index) this.ui.soloSlotIndex = null;
  }

  duplicateSlot(index: number) {
    const free = this.getFirstFreeSlotIndex();
    if (free == null) return null;
    this.slots[free] = { ...this.slots[index] };
    this.ui.selectedSlotIndex = free;
    this.ui.lastEditedSlotIndex = free;
    return free;
  }

  toggleMute(index: number) {
    if (this.ui.mutedSlots.has(index)) this.ui.mutedSlots.delete(index);
    else this.ui.mutedSlots.add(index);
  }

  toggleSolo(index: number) {
    this.ui.soloSlotIndex = this.ui.soloSlotIndex === index ? null : index;
  }

  markPending(index: number) {
    this.ui.pendingWrites.add(String(index));
  }

  clearPending(index: number) {
    this.ui.pendingWrites.delete(String(index));
  }
}
3. matrixrpc.ts
Tu ModuleModMatrix actual ya usa getModulationMetadata y updateModMatrixSlot, así que aquí no reinventaría nada: solo encapsularía esos nombres en un adaptador limpio.

ts
// services/matrixrpc.ts

export class MatrixRpcAdapter {
  async getMetadata() {
    if (!window.omegaRPC) return { sources: [], targets: [] };

    const resp = await window.omegaRPC.call('getModulationMetadata', {});
    const payload = resp?.payload || resp || {};
    return {
      sources: payload.sources || [],
      targets: payload.targets || []
    };
  }

  async getMatrixState() {
    if (!window.omegaRPC) return [];
    const state = await window.omegaRPC.send('getState', {});
    return state?.preset?.modMatrix || state?.modMatrix || [];
  }

  async updateSlotKey(index: number, key: string, value: any) {
    if (!window.omegaRPC) return false;
    await window.omegaRPC.call('updateModMatrixSlot', {
      slot: index,
      key,
      value
    });
    return true;
  }

  async replaceSlot(index: number, slot: any) {
    await this.updateSlotKey(index, 'source', slot.source || '');
    await this.updateSlotKey(index, 'target', slot.target || '');
    await this.updateSlotKey(index, 'amount', slot.amount || 0);
    await this.updateSlotKey(index, 'via', slot.via || '');
    await this.updateSlotKey(index, 'viaAmount', slot.viaAmount || 0);
    await this.updateSlotKey(index, 'active', !!slot.active);
    return true;
  }

  async clearSlot(index: number) {
    return this.replaceSlot(index, {
      active: false,
      source: '',
      target: '',
      amount: 0,
      via: '',
      viaAmount: 0
    });
  }

    const idx = this.store.createDraftAtFirstFree();
    if (idx == null) return;
    await this.rpc.replaceSlot(idx, this.store.slots[idx]);
    this.render();
  }

  async handleCreateAt(index: number) {
    if (this.store.slots[index]?.active) {
      this.handleSlotSelect(index);
      return;
    }

    this.store.patchSlot(index, {
      active: true,
      source: '',
      target: '',
      amount: 0,
      via: '',
      viaAmount: 0
    });
    this.store.selectSlot(index);
    await this.rpc.replaceSlot(index, this.store.slots[index]);
    this.render();
  }

    this.store.patchSlot(index, patch);
    this.store.markPending(index);
    this.render();

    const entries = Object.entries(patch);
    for (const [key, value] of entries) {
      await this.rpc.updateSlotKey(index, key, value);
    }

    this.store.clearPending(index);
    this.render();
  }

  async handleSlotClear(index: number) {
    this.store.clearSlot(index);
    this.store.markPending(index);
    this.render();

    await this.rpc.clearSlot(index);

    this.store.clearPending(index);
    this.render();
  }

  async handleSlotDuplicate(index: number) {
    const newIndex = this.store.duplicateSlot(index);
    if (newIndex == null) return;
    await this.rpc.replaceSlot(newIndex, this.store.slots[newIndex]);
    this.render();
  }

  handleSlotMute(index: number) {
    this.store.toggleMute(index);
    this.render();
  }

  handleSlotSolo(index: number) {
    this.store.toggleSolo(index);
    this.render();
  }

// componentsMatrixOverlayController.js

import { MatrixStore } from './matrixstore.js';
import { MatrixRpcAdapter } from './matrixrpc.js';
import { MatrixComposeView } from './componentsMatrixComposeView.js';
import { MatrixOverviewView } from './componentsMatrixOverviewView.js';
import { MatrixInspectorView } from './componentsMatrixInspectorView.js';

class MatrixOverlayController {
  constructor() {
    this.store = new MatrixStore();
    this.rpc = new MatrixRpcAdapter();
    this.root = null;
    this.dictionaries = { sources: [], targets: [] };
    this.initialized = false;
  }

  async init() {
    if (this.initialized) return;
    this.ensureRoot();
    this.bindGlobalEvents();
    this.initialized = true;
  }

  ensureRoot() {
    if (document.getElementById('omega-matrix-overlay')) {
      this.root = document.getElementById('omega-matrix-overlay');
      return;
    }

    const root = document.createElement('div');
    root.id = 'omega-matrix-overlay';
    root.className = 'omega-matrix-overlay hidden';
    root.innerHTML = `
      <div class="omega-matrix-backdrop"></div>
      <section class="omega-matrix-panel">
        <header class="omega-matrix-header">
          <div>
            <h2 id="omega-matrix-title">MODULATION MATRIX</h2>
            <div id="matrix-header-subtitle">0 active / 32 slots</div>
          </div>
          <div class="omega-matrix-header-actions">
            <button class="matrix-mode-btn active" data-mode="compose">COMPOSE</button>
            <button class="matrix-mode-btn" data-mode="overview">OVERVIEW</button>
            <button id="matrix-add-route-btn">+ ROUTE</button>
            <button id="matrix-close-btn">×</button>
          </div>
        </header>

        <div class="omega-matrix-toolbar" id="matrix-toolbar"></div>

        <div class="omega-matrix-body">
          <main id="matrix-main" class="omega-matrix-main"></main>
          <aside id="matrix-inspector" class="omega-matrix-inspector"></aside>
        </div>
      </section>
    `;
    document.body.appendChild(root);
    this.root = root;
  }

  bindGlobalEvents() {
    window.addEventListener('omega:matrix-open', async (e) => {
      await this.open(e?.detail?.mode || 'compose');
    });

    window.addEventListener('keydown', (e) => {
      if (e.key === 'Escape' && this.store.ui.open) this.close();
    });

    this.root.querySelector('.omega-matrix-backdrop').onclick = () => this.close();
    this.root.querySelector('#matrix-close-btn').onclick = () => this.close();
    this.root.querySelector('#matrix-add-route-btn').onclick = () => this.handleAddRoute();

    this.root.querySelectorAll('.matrix-mode-btn').forEach(btn => {
      btn.addEventListener('click', () => {
        this.store.setMode(btn.dataset.mode);
        this.render();
      });
    });
  }

  async open(mode = 'compose') {
    await this.init();
    this.store.ui.open = true;
    this.store.setMode(mode);

    this.dictionaries = await this.rpc.getMetadata();
    this.store.loadSlots(await this.rpc.getMatrixState());

    if (this.store.ui.selectedSlotIndex == null) {
      const firstActive = this.store.slots.findIndex(s => s.active);
      this.store.selectSlot(firstActive >= 0 ? firstActive : 0);
    }

    this.root.classList.remove('hidden');
    this.render();
  }

  close() {
    this.store.ui.open = false;
    this.root.classList.add('hidden');
  }

  render() {
    const subtitle = this.root.querySelector('#matrix-header-subtitle');
    subtitle.textContent = `${this.store.getActiveCount()} active / 32 slots`;

    this.root.querySelectorAll('.matrix-mode-btn').forEach(btn => {
      btn.classList.toggle('active', btn.dataset.mode === this.store.ui.mode);
    });

    const main = this.root.querySelector('#matrix-main');
    const inspector = this.root.querySelector('#matrix-inspector');

    if (this.store.ui.mode === 'compose') {
      const view = new MatrixComposeView(main, this.store);
      view.render();
      view.bind({
        onAddRoute: () => this.handleAddRoute(),
        onSelectSlot: (index) => this.handleSlotSelect(index),
        onPatchInline: (index, patch) => this.handleSlotPatch(index, patch),
        onClearSlot: (index) => this.handleSlotClear(index),
        onDuplicateSlot: (index) => this.handleSlotDuplicate(index),
        onMuteSlot: (index) => this.handleSlotMute(index),
        onSoloSlot: (index) => this.handleSlotSolo(index)
      });
    } else {
      const view = new MatrixOverviewView(main, this.store);
      view.render();
      view.bind({
        onSelectSlot: (index) => this.handleSlotSelect(index),
        onCreateAtSlot: (index) => this.handleCreateAt(index)
      });
    }

    const inspectorView = new MatrixInspectorView(inspector, this.store, this.dictionaries);
    inspectorView.render();
    inspectorView.bind({
      onPatchSlot: (index, patch) => this.handleSlotPatch(index, patch),
      onDuplicateSlot: (index) => this.handleSlotDuplicate(index),
      onClearSlot: (index) => this.handleSlotClear(index),
      onMuteSlot: (index) => this.handleSlotMute(index),
      onSoloSlot: (index) => this.handleSlotSolo(index)
    });
  }

  handleSlotSelect(index) {
    this.store.selectSlot(index);
    this.render();
  }

  async handleAddRoute() {
    const idx = this.store.createDraftAtFirstFree();
    if (idx == null) return;
    await this.rpc.replaceSlot(idx, this.store.slots[idx]);
    this.render();
  }

  async handleCreateAt(index) {
    this.store.patchSlot(index, {
      active: true, source: '', target: '', amount: 0, via: '', viaAmount: 0
    });
    this.store.selectSlot(index);
    await this.rpc.replaceSlot(index, this.store.slots[index]);
    this.render();
  }

  async handleSlotPatch(index, patch) {
    this.store.patchSlot(index, patch);
    this.render();
    for (const [key, value] of Object.entries(patch)) {
      await this.rpc.updateSlotKey(index, key, value);
    }
    this.render();
  }

  async handleSlotClear(index) {
    this.store.clearSlot(index);
    await this.rpc.clearSlot(index);
    this.render();
  }

  async handleSlotDuplicate(index) {
    const newIndex = this.store.duplicateSlot(index);
    if (newIndex == null) return;
    await this.rpc.replaceSlot(newIndex, this.store.slots[newIndex]);
    this.render();
  }

  handleSlotMute(index) {
    this.store.toggleMute(index);
    this.render();
  }

  handleSlotSolo(index) {
    this.store.toggleSolo(index);
    this.render();
  }
}

export class MatrixStore {
  constructor() {
    this.slots = [];
    this.ui = {
      open: false,
      mode: 'compose',
      selectedSlotIndex: null,
      lastEditedSlotIndex: null,
      soloSlotIndex: null,
      mutedSlots: new Set(),
      filters: { showActiveOnly: true, source: null, target: null, onlyWithVia: false }
    };
  }

  loadSlots(raw) {
    this.slots = Array.from({ length: 32 }, (_, i) => ({
      active: !!raw?.[i]?.active,
      source: raw?.[i]?.source || '',
      target: raw?.[i]?.target || '',
      amount: typeof raw?.[i]?.amount === 'number' ? raw[i].amount : 0,
      via: raw?.[i]?.via || '',
      viaAmount: typeof raw?.[i]?.viaAmount === 'number' ? raw[i].viaAmount : 0
    }));
  }

  getActiveCount() { return this.slots.filter(s => s.active).length; }
  setMode(mode) { this.ui.mode = mode; }
  selectSlot(index) { this.ui.selectedSlotIndex = index; }

  getSelectedSlot() {
    const i = this.ui.selectedSlotIndex;
    return i == null ? null : { ...this.slots[i], index: i };
  }

  getComposeSlots() {
    let rows = this.slots.map((slot, index) => ({
      ...slot,
      index,
      isSelected: this.ui.selectedSlotIndex === index,
      isMuted: this.ui.mutedSlots.has(index),
      isSolo: this.ui.soloSlotIndex === index
    }));
    if (this.ui.filters.showActiveOnly) {
      rows = rows.filter(s => s.active || s.index === this.ui.selectedSlotIndex);
    }
    if (this.ui.filters.onlyWithVia) {
      rows = rows.filter(s => !!s.via);
    }
    return rows;
  }

  getOverviewSlots() {
    return this.slots.map((slot, index) => ({
      ...slot,
      index,
      isSelected: this.ui.selectedSlotIndex === index
    }));
  }

  getFirstFreeSlotIndex() {
    const idx = this.slots.findIndex(s => !s.active && !s.source && !s.target);
    return idx >= 0 ? idx : null;
  }

  createDraftAtFirstFree() {
    const idx = this.getFirstFreeSlotIndex();
    if (idx == null) return null;
    this.slots[idx] = { active: true, source: '', target: '', amount: 0, via: '', viaAmount: 0 };
    this.ui.selectedSlotIndex = idx;
    return idx;
  }

  patchSlot(index, patch) { this.slots[index] = { ...this.slots[index], ...patch }; }
  clearSlot(index) { this.slots[index] = { active:false, source:'', target:'', amount:0, via:'', viaAmount:0 }; }
  duplicateSlot(index) {
    const free = this.getFirstFreeSlotIndex();
    if (free == null) return null;
    this.slots[free] = { ...this.slots[index] };
    this.ui.selectedSlotIndex = free;
    return free;
  }

  toggleMute(index) {
    this.ui.mutedSlots.has(index) ? this.ui.mutedSlots.delete(index) : this.ui.mutedSlots.add(index);
  }

  toggleSolo(index) {
    this.ui.soloSlotIndex = this.ui.soloSlotIndex === index ? null : index;
  }
}
matrixrpc.js
Tu frontend actual usa window.omegaRPC.call('getModulationMetadata', {}) y window.omegaRPC.call('updateModMatrixSlot', { slot, key, value }), así que mantengo eso tal cual.

js
export class MatrixRpcAdapter {
  async getMetadata() {
    const resp = await window.omegaRPC.call('getModulationMetadata', {});
    return {
      sources: resp?.payload?.sources || [],
      targets: resp?.payload?.targets || []
    };
  }

  async getMatrixState() {
    const state = await window.omegaRPC.send('getState', {});
    return state?.preset?.modMatrix || state?.modMatrix || [];
  }

  async updateSlotKey(index, key, value) {
    await window.omegaRPC.call('updateModMatrixSlot', { slot: index, key, value });
    return true;
  }

  async replaceSlot(index, slot) {
    await this.updateSlotKey(index, 'source', slot.source || '');
    await this.updateSlotKey(index, 'target', slot.target || '');
    await this.updateSlotKey(index, 'amount', slot.amount || 0);
    await this.updateSlotKey(index, 'via', slot.via || '');
    await this.updateSlotKey(index, 'viaAmount', slot.viaAmount || 0);
    await this.updateSlotKey(index, 'active', !!slot.active);
    return true;
  }

  async clearSlot(index) {
    return this.replaceSlot(index, {
      active: false, source: '', target: '', amount: 0, via: '', viaAmount: 0
    });
  }
}

8. Mi recomendación final de refactor
El cambio clave no es técnico sino de frontera de responsabilidad: ModuleModMatrix deja de ser “editor” y pasa a ser “entry point”. Eso es lo más coherente con tu arquitectura actual porque ModuleManager sigue gestionando módulos de rack como hasta ahora, mientras que la experiencia compleja vive en un controlador global lazy-loaded, igual que otras vistas avanzadas y modales ya existentes en OMEGA.

La consecuencia práctica es buena: tocas poco el core del sistema, reutilizas getState, getModulationMetadata y updateModMatrixSlot, y evitas que el rack principal vuelva a convertirse en una tabla de mantenimiento.

El siguiente paso útil sería darte el contenido completo de los tres archivos de vista (componentsMatrixComposeView.js, componentsMatrixOverviewView.js, componentsMatrixInspectorView.js) con formato ya 100% JS como el resto de tu repo, para que literalmente los pegues.
